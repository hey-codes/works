# codymitch.works

Where my facilities work lives: 13 years, 9 brands, 400+ locations, on one page you can read in a couple of minutes, next to a map of every site.

Next.js (App Router), TypeScript, static export, deployed on Vercel. All content is in `src/data/resume-data.ts`; updating the site is a text edit and a deploy.

```sh
pnpm install
pnpm dev
```

Live at [codymitch.works](https://codymitch.works). Design and product notes, and the checklist of open items, are in `docs/`.
